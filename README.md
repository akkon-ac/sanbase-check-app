# SanBase Check – Web-App

Materialprüfung nach Checklisten, direkt im Browser und auch offline.

**App öffnen:** https://akkon-ac.github.io/sanbase-check-app/

Im Browser (Chrome, Edge, Safari) kann die App installiert werden („Zum Startbildschirm hinzufügen“ bzw. „App installieren“). Danach startet sie auch ohne Internet.

## Daten

Dieses Repository enthält nur die gebaute Web-App, **keine Daten**. Checklisten, Items und Nutzer kommen ausschließlich aus den Datenbankdateien (`.sanbase-check`, `.sanbase-stamm`, `.sanbase-archiv`), die in der App geöffnet werden. Sie bleiben auf dem jeweiligen Gerät im Speicher des Browsers.
